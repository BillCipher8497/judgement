# N3 source review draft — not a launch token

Manual review 2026-11-18, before N3 scientific data. Synthetic/seed/full-suite
gates are still pending while N2 owns the sole scientific worker. Owner permits
independent Codex continuation; any eventual source token is Codex self-review,
not Claude approval. New scientific results remain local for later external audit.

- Private policy sees only a detached PublicSnapshot. Its missing legacy
  winner properties are supplied by a new subclass derived from public trick
  cards. No `_s`, other hands, sampler worlds, teacher labels or future outcomes
  enter the683-vector or neural play method. Remaining-card counts are public.
- Context acceptance is own-hand SHA partition and the first observable active
  hero event. The hero's two cards must both be legal and own remaining need
  live. No hidden opponent/stock filter or hidden teammate-stage indicator.
  Equal accepted strata do change the natural mixture; no inverse-frequency
  correction is claimed. Full-game utility deals are unfiltered.
- All16worlds are structural-uniform draws, not a true policy-conditioned
  posterior. PI-neutral-MaxN continuation differs from private TA opponents.
  Labels are averaged after each world's hard/uniform/set operation. Public
  hit score is constant across worlds, enabling only the restricted M15 binary
  alignment. This does not imply actual-game optimality or a BCE-only advantage.
- Same data/worlds/initializations and shuffled rows within each model family.
  Five objectives, same-set CE, linear hard/set and explicit-offset controls.
  All arms retain baseline inputs. Parameter counts, selected epochs and blends
  differ; the linear interaction is a selected-pipeline comparison, not a pure
  nonlinearity experiment. No-offset is not removal of baseline information.
- Fixed50epochs/five fits. Validation alone chooses epoch/blend and best
  ensemble; candidate values/intervals are reused-selection diagnostics.
  No held-context or game-stage selection. Two fixed2000block game stages,
  paired deals, hero g%4, ties-as-win recomputed from totals. All nulls retained.
- Every context and teacher world is scheduled for a fresh manual solver/rules/
  seed-prefix check, reusing sampler and policy functions as definitions. All
  held-label/model-selection/game-CI calculations plus144manual full-game
  replays are separate checks. Not every game is independently re-simulated.
- Atomic incremental raw writes, immutable per-epoch Adam states with a pointer
  updated after persistence, retained partial game arms and finite I/O retries.
  Source/model/data hashes checked. At most two preallocated3hscientific
  windows; before each, a fresh absolute timer is recorded. Pilot forecast is
  an approximate scheduling gate, not a guarantee. Failed scope is reported.

Before launch: run self_check.py, metadata-only run.py --preflight, the full
engine pytest gate; inspect outputs and actual source fingerprint; write the
distinct Codex source token, then commit this source-only scope locally.
